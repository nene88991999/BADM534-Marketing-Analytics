# Agent Guide for Slides

Course decks are stored in `../Lectures/`. Follow [the current lecture guide](../Lectures/AGENTS.md), [the session plan](../Lectures/SESSION_PLAN.md), and [the art direction](../Lectures/ART_DIRECTION.md). The latest supplied template uses parchment backgrounds, 16:9 Beamer, 14-point base text, Illinois colors, and Chinese ink-and-color illustrations. It supersedes the earlier white-background preference.

Keep the historical reference templates in Dropbox only. They do not establish course dates, requirements, or content.
