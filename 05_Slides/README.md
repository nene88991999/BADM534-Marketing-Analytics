# Slides

The course decks are in [Lectures](../Lectures/README.md): 15 sessions with PDFs, editable LaTeX, complete Markdown companions, and a 170-minute plan for each meeting.

The companion should identify the lecture/module, version, learning objectives, slide-number anchors, chart descriptions, definitions, equations, and referenced resources. Identify information omitted from a summary. Link to the original deck and any related lab.

Lecture decks use Nathan Yang's latest 16:9 LaTeX Beamer format: 14-point base text, parchment backgrounds, blue text, orange rules and bullets, editable TikZ figures, Chinese ink-and-color illustrations, and optional presenter notes. Course decks follow the UIUC palette. Follow the current [lecture authoring guide](../Lectures/AGENTS.md).
