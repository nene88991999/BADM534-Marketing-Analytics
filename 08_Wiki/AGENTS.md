# Agent Guide for the Wiki

Follow the root guide and writing preferences. The `pilot/` page is an original static learning example. It establishes no assessment requirement and has no proven learning effect. Preserve a complete Markdown companion and stable relative links to source notes, data, and code.

Keep synthetic scenarios distinct from empirical findings. An arithmetic result must not become a causal or moral conclusion without additional premises. Do not send learner responses to a model service or add telemetry without explicit authorization. Keep answer feedback educational and public; private graded solutions do not belong here.

For changes, run the Python reference calculation, regenerate the visible code and browser reference data, check JavaScript calculations independently, and inspect the actual browser interaction. Verify keyboard navigation, input constraints, scenario changes, reset, narrow layout, links, and meaningful no-JavaScript text. File generation does not establish deployment. Use the requested GitHub hosting destination when deployment is authorized.
