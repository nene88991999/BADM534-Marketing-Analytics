## Adding an Example

Use a descriptive filename with a module prefix, such as `M02_Customer_Summary.py`. For examples with several files, use a dedicated subfolder with its own README.

Document the marketing question, inputs, dependencies, run command, expected output, and a simple check of the result. Use relative data paths and link to the relevant [data dictionary](../03_Data/README.md). Label synthetic data clearly, preserve source attribution and licenses, and record whether the example has been executed successfully.

## Guidance for Students and Agents

Read the root [agent guide](../AGENTS.md) before adapting an example. Explain the purpose of the code and its analytical assumptions, inspect the inputs, and verify the output with a small example. Identify any changes made with AI assistance. Follow the relevant assignment's rules when using sample code in assessed work.
