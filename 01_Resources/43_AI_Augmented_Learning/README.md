# AI-Augmented Learning and Independent Judgment

An instructor deciding how to present an analytical argument needs to preserve its meaning while helping students investigate it independently. The course applications connect explanation, editable diagrams, executable calculations, and questions that expose unsupported premises.

## Scope of Evaluation

Source fidelity, code correctness, usable navigation, and learning are separate outcomes. A course evaluation should specify each outcome and its comparison. Students can inspect the original argument even when an adaptation is easier to read. A generated explanation must preserve consequential restrictions and remain open to a supported objection. No experiment with course students has been conducted, and no learning benefit is claimed for the pilot.
