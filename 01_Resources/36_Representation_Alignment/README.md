# Representation Alignment and Marketing Decisions

A firm replacing a text encoder needs to know whether the existing classifier can use the new coordinates. Compare geometry, compatibility with the classifier, and performance after retraining. These questions have distinct evaluation targets.

[Plato's Key](https://hazyresearch.stanford.edu/blog/2026-11-25-platos-key), by Vivien Cheng, Jerry Liu, Morris Yau, and Chris Ré, motivates the comparison through factual recall in language models. The [source review](SOURCE_REVIEW.md) records the experiment's scope and related research. The course uses original calculations and local lexical representations of mHealth descriptions.
