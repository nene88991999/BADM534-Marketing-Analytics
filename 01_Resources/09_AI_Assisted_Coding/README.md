# AI-Assisted Coding

Updated October 23, 2026. 18 curated resources. [Master Guide](../README.md).

Use coding assistants throughout the course. Require a clear problem specification, small implementation steps, checks against known cases, and an explanation of the resulting analysis. The provider guides are alternatives, not a requirement to subscribe to every tool.
