Generated by `../error_costs.py` on November 27, 2026. The observation unit is a hypothetical case. Harm prevalence is 0.10; the null and harmful-state signals are normal with variance 1 and means 0 and 2. Losses use illustrative comparable units per case, with zero loss for correct decisions.

The denominator for a false-positive rate is harmless cases; the denominator for a false-negative rate is harmful cases. Power equals one minus the false-negative rate. Expected loss averages over all cases using the stated prevalence. The calculation uses exact normal probabilities evaluated numerically and has no sampling error bars.
