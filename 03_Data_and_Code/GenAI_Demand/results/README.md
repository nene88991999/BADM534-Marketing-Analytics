# Generative-AI Demand Results

All files are generated by the three offline course programs. Public pageviews are analyzed as a supplied dated capture; all subscription results are synthetic. See the [data dictionary](../DATA_DICTIONARY.md) for units and output fields.

- **Public signals:** 122 complete days for two selected Claude titles. June–September change is -85.06% for the older title and -16.66% for their sum. These are pageview events, not unique users, payments, or an exhaustive brand-attention measure.
- **Adoption:** 1,741 of 60,000 simulated consumers hold 1,813 subscriptions in April 2026. There are 71 multihomers, giving 4.078% conditional multihoming. The aggregate adoption path is targeted by the generator.
- **Fixed-cohort retention:** Among 430 January 2025 OpenAI subscribers, 162 hold OpenAI in January 2026, 90 hold other providers only, and 178 hold no paid provider. Only 129 hold OpenAI throughout all intervening months. These counts use the same original cohort.
- **Acquisition:** The last month has 401 newly held provider events from 400 consumers: 197 first entries, 157 returns to the category, 32 complete provider switches, and 15 provider additions.
- **Price projections:** The same 179 provider-months yield stock and flow log-odds slopes of -0.03004 and -0.04987 per dollar. Exact binary-model probabilities on the same price design recover -0.06000. The dynamic-panel slopes have a descriptive interpretation; no confidence interval or causal estimate is reported.

`verification.json` records the runtime, eight counterexample tests, and independent numerical checks. `../manifest.json` records source hashes. The original network collectors, notebook, and complete panel simulation were inspected but not executed in this course adaptation.
