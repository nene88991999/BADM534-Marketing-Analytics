# Agent Guide for Workflow Evaluation

Read README.md, DATA_DICTIONARY.md, and EXPERIMENT_PROTOCOL.md before using these tasks. The root course guide and current assignment rules govern student assistance.

- Preserve the prior-period roster, half-open date interval, distinct-day unit, and zero-log users. Recorded logging is not food intake or an account-enrollment measure.
- Keep actual task calculations separate from invented test cases and hypothetical cost inputs.
- The saved outputs contain no measured LLM performance. Never present the four configurations as an executed experiment.
- Do not expose final evaluation answers during a measured model comparison. Restrict the task workspace explicitly; public filenames are not an access boundary.
- The CSV checker reads data only. It does not authorize or isolate generated-code execution. Review permissions and commands before a separately requested run.
- The task builder reads the existing local mHealth release and verifies its hash. It does not upload records to an external service.
- Maintain full Python blocks in the notes when changing their matching programs. Run the independent checks and preserve source and input hashes.
