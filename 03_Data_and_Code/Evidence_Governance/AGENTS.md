Read the root guide and this folder's README before interpreting the results. The program and eight claims are original teaching examples. The source table contains published estimates; the approval, decision history, and claim judgments are fictional. Preserve those distinctions.

Keep source records, numerical calculations, claim wording, and action recommendations separate. A source hash identifies the bytes used; it establishes no substantive truth. Use the complete eight-case comparison when assessing this program. Explain the accepted prose/metadata contradiction. Retain superseded decisions and the reasons for correction in the fictional history.
