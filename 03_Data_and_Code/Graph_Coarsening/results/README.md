# Exact Synthetic Results

`network.json` and `zones.csv` are generated by `../compress_network.py`. `labels.json` is generated by `../evaluate_labels.py`. Both read `../data/cases.json`. All records and label values are synthetic, with no sampling or model calls.

The retail outputs use 400 people across four zones. The original access count is 300. The coarse interpretation counts 400 by discarding internal travel. Label outputs use separate three-node and eight-customer examples. Definitions and denominators are in [the data dictionary](../DATA_DICTIONARY.md). Published benchmark rows are not generated by these programs.
