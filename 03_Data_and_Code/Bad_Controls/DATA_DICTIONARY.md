# Data Dictionary

All rows are generated by the named programs. No source data are required.

| File | Observation Unit | Fields and Units |
| --- | --- | --- |
| `control_observations.csv` | Case × shock combination, 80 rows | `treatment`, `control`, and `outcome` are synthetic units; `weight=1/16` within each case |
| `control_estimates.csv` | Causal structure, 5 rows | Slopes in outcome units per treatment unit; analytical values computed separately from OLS |
| `panel_population.csv` | Weighted population cell, 16 rows | `w` is a binary baseline variable; `d` is treatment; `u,e` are independent ±1 shocks; `weight` sums to one; `x0=0`; `x1_untreated=w+u`; observed `x1=x1_untreated+2d`; `y0=100`, `y1=100+4d+3x1_untreated+e` |
| `panel_estimates.csv` | Method, 4 rows | `estimate`, `true_att`, and `analytical` in outcome units; no sampling uncertainty |
| `project_panel.csv` | Utility × synthetic date, 12 rows | Four utilities; dates 2023Q1, 2024Q1, 2025Q4; mutually exclusive project states; `operating` is 0/1; `price_usd_mwh` is dollars/MWh |
| `window_comparisons.csv` | Baseline and donor choice, 3 rows | Treated and weighted-donor changes; difference in dollars/MWh |
| `donor_sensitivity.csv` | Imposed canceled-donor increment × weight, 12 rows | Increment in dollars/MWh, weight in [0,1], `gap=10-weight*increment` |
| `selected_populations.csv` | Imposed cost scenario, 2 rows | Equal-weight means across three proposed-project utilities or the single operating utility, dollars/MWh; status composition is fixed |

The pending project has not opened by the synthetic cutoff. Its future status is unobserved. A cancellation is distinct from an unfulfilled request, a duplicate request, a postponement, and a pending project. None of these labels alone establishes a household charge.
