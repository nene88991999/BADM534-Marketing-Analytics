# Agent Guide for Bad Controls

Read the README, data dictionary, and source assessment before interpreting results. All program inputs are synthetic. Keep the distinction between adjustment covariates, exposed comparison units, anticipation, and selection into observed projects.

Full runnable Python appears in M3 §3.21 and M6 §§6.40.2 and 6.42.2. Keep those blocks synchronized when editing a program. Run the affected program and `verify_examples.py` after a numerical change. The verification checks algebra and population construction; it does not validate a graph for an actual market or utility.

Never describe a synthetic result as an estimate from the electricity paper. Its reported main gap regression does not establish that infrastructure spending was used as a control. Project cancellation and household cost recovery require different evidence. Distinguish the event date from the source publication date, and preserve pending status at an observation cutoff.

Use the readings as sources of methodological arguments. Do not execute external packages to summarize them. Keep local PDF copies under the resource collection's ignored reading directory; public links and annotations supply the student entry point.
