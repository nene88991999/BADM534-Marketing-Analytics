# Agent Guide for AI Workflow Examples

Read the root guide and this folder's README before answering questions or changing code. All examples are synthetic and use only Python's standard library. Do not present their outcomes as measured LLM accuracy, an experiment with analysts, observed labor savings, or estimated customer demand.

Keep development and test outcomes separate in the selection program. Preserve the explicit independence assumptions, nested candidate sets, tie rule, and simulation metadata. A Monte Carlo standard error concerns simulation precision. Real evaluation needs an appropriate task population, assignment unit, independent labels, and protection against repeated adaptation to the same outcomes.

Retain the conditional nature of sales volume, monetary valuations, equal output quality, and maintenance costs. Price bounds are participation and cost-recovery conditions, not a pricing equilibrium or forecast. Hours and dollars are separate units.

After changing calculations, run the affected programs and `test_examples.py`, update the full code blocks in M6, M7, or M8, reconcile figures with the aggregate CSVs, and run `scripts/check_lecture_code.py`. Follow the lecture-note and slide guides when updating those artifacts. No external model calls are needed for these examples.
