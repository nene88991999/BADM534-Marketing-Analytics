# Agent Guide for LLM Revalidation

Read README.md and DATA_DICTIONARY.md first. Keep published research outputs distinct from constructed upgrade cases. The snapshot calculations reuse the authors' estimates; they are not fresh model runs or an independent reproduction of the research pipeline.

Preserve unreliable comparisons, right censoring, the fixed observation end, the source license, and the pinned source version. A fitted expiration category does not mean zero error on every model. A selected literature sample does not establish a general lifespan for AI research.

For upgrades, preserve paired case IDs and segment denominators. Judge versions, output versions, parser changes, task mix, and changed labels can all affect comparisons. Synthetic dollar losses and scores are imposed examples. Do not present them as measured performance or recommend a provider on their basis.

Run affected programs and the small-case tests after changes. Refresh matching full-source blocks in the module notes and reconcile the editable TikZ figures against the outputs. No API calls or dependency installation are necessary for these examples.
