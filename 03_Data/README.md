# Course Data

**Status: no course-selected dataset released.** Candidate datasets are in the [resource library's dataset guide](../01_Resources/10_Datasets_and_Project_Resources/Dataset_Guide/README.md) and [additional dataset collection](../01_Resources/20_Datasets/README.md).

For each selected dataset, create a folder containing the files, a `README.md`, and a data dictionary. Record the source, retrieval date/version, license, observation unit, time range, units, missing-value codes, exclusions, and processing steps. Preserve original and derived data separately. Label synthetic data explicitly.

Keep identifiable student records and restricted research data outside this repository.
